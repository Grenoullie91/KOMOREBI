Inter
=====

Die Schriften in diesem Ordner stammen aus der systemweit installierten
Inter-Familie (SIL Open Font License 1.1, https://rsms.me/inter/).
Es wurden keine Dateien aus fremden Projekten uebernommen - die Glyphen
sind freie Arbeit von Rasmus Andersson und Koautoren unter der OFL 1.1
lizenziert, die eine uneingeschraenkte Weiterverwendung erlaubt.

Verwendet werden:
  Inter-Regular.otf        Fliesstext
  Inter-SemiBold.otf       Buttons, Zahlen
  Inter-Bold.otf           Ueberschriften
  InterDisplay-Bold.otf    Logo / Display

Die OFL 1.1 verlangt, die Lizenz mitzuliefern und die Namen der Autoren
nicht als Marke zu verwenden. Beides ist hier eingehalten: Komorebi ist ein
eigenstaendiger Titel und benutzt keinerlei geschuetzte Schrift-Marke.

Die vollstaendige SIL Open Font License 1.1 liegt in diesem Verzeichnis
unter OFL.txt. Sie enthaelt auch den Copyright-Hinweis der Inter Project Authors.
Offizielle Quelle: https://github.com/rsms/inter

Die Schriftdateien werden zusammen mit diesem Lizenzhinweis und
der vollstaendigen OFL-1.1-Lizenz weitergegeben.
